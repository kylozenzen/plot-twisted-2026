# Ticket stub clue promos

Social graphics for the Plot Twisted launch. Each one shows a real clue from the game, never the answer, and asks people to guess the movie in the comments.

- Size: 1080x1350 (4:5 feed)
- `posts/`: 12 posts, 4 in each design, numbered in suggested posting order. The order rotates the three designs so no two posts in a row look alike.
- `options/`: the three design options (Admit One, Marquee, Matinee Minimal).

Answers are deliberately left out of the images, file names and this folder.
