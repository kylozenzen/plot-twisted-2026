Keep the theater

Install Plot Twisted. Skip the app-store side quest.

Add the game to your home screen or desktop and launch straight into the theater. It stays a web app, updates automatically, and does not ask for an account.

Play without installing
Checking what your browser supports…


iPhone or iPad

Safari
Home screen
  1. Open Plot Twisted in Safari.
  2. Tap the Share button.
  3. Choose Add to Home Screen, then confirm.
The PT icon will appear alongside your other apps and open directly into the game.
🤖

Android

Chrome
Install app
  1. Tap the install button on this page when it is available.
  2. Or open Chrome's menu and choose Install app or Add to Home screen.
  3. Confirm the installation.
The exact menu wording can vary slightly by browser and Android version.
💻

Mac, Windows, or Chromebook

Chrome or Edge
Desktop app
  1. Click the install icon in the address bar when it appears.
  2. Or open the browser menu and choose the option to install Plot Twisted.
  3. Confirm, then launch it from your applications or dock.
No separate download package is required; the browser handles the installation.
